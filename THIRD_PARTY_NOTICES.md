# Third-party UI attribution

Returnly uses two free Magic UI components, adapted to the existing Framer Motion dependency, Returnly motion tokens and reduced-motion behavior:

- Blur Fade: https://magicui.design/r/blur-fade.json → `app/components/returnly/Reveal.tsx`
- Border Beam: https://magicui.design/r/border-beam.json → `app/components/returnly/BorderBeam.tsx` (single entrance sweep)
